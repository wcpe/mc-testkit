# 架构不变量（防架构漂移）

> 以下是本项目锁定的架构约束（依据 `docs/ARCHITECTURE.md` 与 `docs/adr/`）。**违反任一条即为架构漂移。**
> 确需改变某条 → 先写新 ADR 取代旧决策、经确认后再改；**禁止在代码里静默违背**。

## 1. 核心边界与依赖方向
- 编排插件**不得反向依赖**任何消费项目或 `template/`。
- 服务端 / 代理的下载与运行由**本插件内置的下载/运行模块**完成（自实现，见 ADR-0001）——**不外挂第三方下载库**。
- `template/` 是**纯拷贝脚手架**：不被插件运行期代码依赖、不参与插件构建产物。
- 编排在**内置下载/运行模块之上装配**——拓扑、任务、机器人驱动、判定、收尾、环境契约，越过这条边界即漂移。

## 2. 简单优先（禁用重型件）
- 内置下载/运行模块**保持精简**：只覆盖五平台（Paper/Folia + Velocity/Waterfall/BungeeCord）的 jar 解析 + 缓存 + 启动；**不**搬运插件市场下载（Modrinth/Hangar/GitHub/Url）等非必需能力（镀金）。
- 禁止为编排引入容器编排 / 分布式调度 / 消息中间件等重型件。
- 本期禁止发布共享 Kotlin 桩基类库 / npm 机器人包（ADR-0002，留 P2）。
- 不为未来平台 / 能力预留空壳抽象、配置项、字段（需要时再加）。

## 3. 真源 / 一致性
- **测试结论以桩写出的结果文件为唯一权威**：编排 / 任务不得绕过结果文件自行判 PASS。
- 版本号唯一来源是根 `VERSION` 文件。
- 环境契约（机器人协议版本、代理在线模式、BungeeCord 后端配置、依赖注入校验）**固化在插件一处**，不在各消费方散落复制。

## 4. 技术栈锁定
- Kotlin + Gradle（`java-gradle-plugin` + `kotlin-dsl`）实现插件；服务端 / 代理经**本插件内置下载/运行模块**（自实现，见 ADR-0001）；机器人 Node(≥18) / mineflayer。
- 构建脚本一律 Gradle Kotlin DSL（KTS）、实现一律 Kotlin（不写 Groovy DSL、不用 Java 写实现）。
- **Kotlin 语言 / API 版本锁 `1.9`**：保证构件同时被 K1（Gradle 8.x）与 K2（Gradle 9.x）消费方加载（见 ADR-0005）；不擅自抬高。
- 换语言 / 换 Gradle 形态 / 换下载底座 / 改 Kotlin 版本锁 = 架构决策 → 走新 ADR，不擅自更换。

## 红线（出现即停止并先确认）
外挂第三方下载 / 运行库依赖（已改为内置自实现，见 ADR-0001）· 下载模块镀金（搬运插件市场下载 / 容器化等不需要的能力）· 插件反向依赖消费项目或 `template/` · 编排绕过结果文件自行判 PASS · 破坏「`VERSION` 唯一真源 / 环境契约单点」· 实现 Spigot/Bukkit/Sponge（不在计划内）或发布共享桩/机器人库（镀金）· 写死本机绝对路径 · 擅自换栈 · 抬高 Kotlin 语言/API 版本破坏 K1/K2 兼容 · 静默违背任一已接受 ADR。
